sistemas operativos

El sistema operativo es el software que coordina y dirige todos los servicios y aplicaciones que utiliza el usuario en una computadora

windows

Windows es el sistema operativo informático de Microsoft.

maCOs

Mac OS es el sistema operativo del ordenador personal Apple. Está desarrollado y comercializado por Apple Inc.

Linux

Linux es el nombre que reciben una serie de sistemas operativos de tipo Unix bajo la licencia GNU GPL (General Public License o Licencia Pública General de GNU) que son su mayoría gratuitos y con todo lo necesario para hacer funcionar un PC, con la peculiaridad de que podemos instalar un sistema muy ligero e ir añadiendo todo lo necesario posteriormente o según lo vayamos necesitando.

freeBSD

FreeBSD es un sistema operativo libre y de código abierto de tipo Unix que desciende de la Berkeley Software Distribution (BSD), basada en Research Unix.
